# Bienvenida

Este es el vault de **Documentos** del panel. Sólo lo ve el administrador. Los archivos viven en una carpeta del servidor (`vault/`) que no se sirve por URL: se leen y se escriben por la API, con tu sesión.

## Cómo se usa

- El árbol de la izquierda es el de carpetas. Clic para abrir o plegar.
- Hasta **5 subcarpetas**. Más profundo, la API rechaza la ruta.
- Todo es markdown (`.md`). La vista de la derecha lo interpreta.
- Enlaces internos al estilo Obsidian: `[[Bienvenida]]` o `[[carpeta/nota|texto]]`.
- **Ctrl+K** busca. **Ctrl+S** guarda. **Ctrl+E** alterna lectura y edición.
- Hay autoguardado a los ~1,2 s si hay cambios. El punto ámbar es “sin guardar”.

## Empezar

Creá una carpeta (Operación, Comercial, Legal…) y una nota adentro. El resto es escribir.
